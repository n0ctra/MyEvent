# MyEvent Tech 🎟️

Plataforma web de reservas para experiencias culturales, gastronómicas y cafeteras del Eje Cafetero colombiano. Permite a los **organizadores** publicar eventos y a los **asistentes** reservar plazas en segundos con confirmación inmediata.

## 📖 Descripción

**MyEvent Tech** resuelve la falta de una plataforma especializada para reservar experiencias locales en el Quindío. Centraliza la publicación y reserva de eventos culturales, con:

- Catálogo de eventos filtrable por categoría.
- Detalle completo: galería, agenda, ubicación, FAQs.
- Sistema de reservas con código único de acceso (`MET-XXXXXXXX`).
- Autenticación con roles: **asistente** y **organizador**.
- Panel de "Mis reservas" con estados: próximas, pasadas y canceladas.
- Publicación de eventos por parte de organizadores.

## ✨ Características

### Para asistentes
- 🎟️ Reservar plazas con stepper interactivo.
- 📱 Código QR y pase descargable para cada reserva.
- 📊 Estadísticas personales de actividad.
- 🔔 Alertas de cupos liberados.
- 🔗 Sistema de referidos.

### Para organizadores
- 📝 Formulario de creación con vista previa en tiempo real.
- 💰 Cálculo automático de recaudación neta (comisión 6%).
- 💾 Guardado automático de borradores.
- 📈 Gestión de aforo en tiempo real.
- ⏳ Lista de espera automática.

### Generales
- 🔐 Autenticación con `localStorage` (mock).
- 📱 Diseño **100% responsive** (mobile-first).
- 🎨 Sistema de diseño con tokens de color Material 3.
- ⚡ ES Modules con arquitectura de stores.
